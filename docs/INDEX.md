## 📝 文档编写规范

### 文档命名
- 主文档: `README.md`
- 指南文档: `xxx_guide.md`
- 更新日志: `CHANGELOG_xxx.md`
- 快速参考: `xxx_QUICK_REF.md`

### 文档结构
1. 标题和简介
2. 目录（可选）
3. 正文内容
4. 相关链接
5. 更新记录

### Markdown 规范
- 使用标准 Markdown 语法
- 代码块指定语言
- 表格对齐
- 适当使用 Emoji
